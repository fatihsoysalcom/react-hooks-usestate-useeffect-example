# React Hooks useState useEffect Example

This example demonstrates the fundamental React Hooks: `useState` and `useEffect`. It shows how `useState` enables functional components to manage their own state, replacing the need for class component state. It also illustrates how `useEffect` can handle side effects like data fetching and DOM manipulation (e.g., updating the document title), providing lifecycle-like capabilities in functional components.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser.
